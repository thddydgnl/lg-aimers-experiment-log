# Official data setup

대회 데이터는 이 저장소에 포함하지 않는다. 공식 배포 파일을 다음 위치에 둔다.

```text
open/
  data/
    train.csv
    test.csv
    trackman_history.csv
    sample_submission.csv
```

실제 공식 파일명이 다르면 [`data_description.md`](data_description.md)와 실험 코드의 입력 검증을 우선한다. 외부 데이터, 외부 API, 다른 참가자의 비공개 데이터는 사용하지 않는다.
