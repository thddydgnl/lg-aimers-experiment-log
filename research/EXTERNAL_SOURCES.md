# External source handling

원본 작업 폴더에 있던 제3자 저장소 복제본은 이 저장소에 다시 포함하지 않았다. 자체 작성 비교·조사 결과는 다음 문서에 남아 있다.

- [`ANALOGOUS_DATA_METHODS_AND_EXPERIMENTS.md`](ANALOGOUS_DATA_METHODS_AND_EXPERIMENTS.md)
- [`RELATED_WORK_AND_EXPERIMENT_ROADMAP.md`](RELATED_WORK_AND_EXPERIMENT_ROADMAP.md)

외부 구현을 다시 참고할 때는 원 출처의 최신 저장소와 라이선스를 직접 확인한다. 복사 코드가 최종 실험에 사용됐다면 해당 실험 코드와 결과의 provenance를 별도로 검토한다.
