# 기본 베이스라인 실험 보고서

> 실행일: 2026-08-16  
> 목적: 2025 평가 데이터에 적용할 모델을 개발하기 전에, 누수 없는 시간 순 검증과 최소 비교 기준을 고정한다.
> 현재 PC 재검증: 2026-08-17, Windows PowerShell 환경은 [`../LOCAL_ENVIRONMENT.md`](../LOCAL_ENVIRONMENT.md)를 따른다.

## 1. 결론

기본선은 하나가 아니라 두 개로 관리하는 편이 안전하다.

- **안정성 기준 기본선: `linear_sgd`**
  - 2022·2023·2024 세 rolling fold에서 모두 양의 Brier skill을 기록했다.
  - 3개 시즌 평균 Brier는 `0.24806782`로 비교 모델 중 가장 낮다.
  - 정규화가 강해 급격한 분포 변화에서 확률이 덜 극단적이다.
- **최근 시즌 성능 기준: `hist_gradient_boosting`**
  - 주 검증인 2024에서 Brier `0.24834400`, 환산 점수 `585.6`으로 1위다.
  - 그러나 2023의 `game_type=F` 체제 변화에서 Brier `0.25374881`로 크게 실패했다.
- **공식 구조 기준: `official_rf`**
  - 2024 Brier `0.24876728`, 환산 점수 `416.2`다.
  - 공식 제공 pickle을 검증에 그대로 사용하지 않고, 동일 구조를 과거 시즌만으로 재학습했다.

따라서 현 단계에서 HGB 하나를 최종 모델로 확정하지 않는다. 다음 실험은 선형 모델의 시간 추세 안정성과 HGB의 비선형 변별력을 결합하고, 2023 같은 체제 변화에 견디는 calibration을 만드는 방향이 우선이다.

## 2. 검증 설계

### 2.1 Rolling season holdout

| Fold | 학습 기간 | 검증 기간 | 학습 행 | 검증 행 |
| --- | --- | --- | ---: | ---: |
| 1 | 2019~2021 | 2022 | 728,588 | 247,472 |
| 2 | 2019~2022 | 2023 | 976,060 | 245,525 |
| 3, 주 검증 | 2019~2023 | 2024 | 1,221,585 | 253,507 |

각 fold의 `model.fit`과 행별 추론에는 해당 검증 시즌의 Target, 검증 전체 통계, 다른 검증 행의 정보를 사용하지 않았다. 제공된 `asof_*`는 각 투구 이전 이력으로 만들어진 공식 피처이므로 그대로 사용할 수 있지만, 검증 데이터에서 새 집계치를 만들지는 않았다. `row_id`도 입력에서 제외했다.

이 수치는 완전히 손대지 않은 최종 성능 추정치가 아니라 **모델 개발용 rolling CV**다. 선형 모델의 정규화 강도 등 설계 선택에는 과거 fold의 진단 결과가 반영돼 있다. 향후 실험도 동일 fold로 비교하되, 최종 선택이 끝난 뒤에는 별도 pseudo-holdout 또는 시간 순 nested validation으로 일반화 오차를 다시 확인한다.

### 2.2 평가 지표

검증 Target 평균을 `r`, 예측을 `p`, 정답을 `y`라 하면 다음을 사용했다.

```text
BS = mean((p - y)^2)
reference_BS = r * (1 - r)
raw_skill = 1 - BS / reference_BS
local_competition_score = max(0, 100000 * raw_skill)
```

이 환산 점수는 검증 세트에서 공식을 재현한 값이지 실제 리더보드 점수가 아니다. 대회 점수는 음의 skill을 0으로 자르므로, 모델 안정성을 비교할 때는 Brier와 clipping 전 `raw_skill`도 함께 봐야 한다.

## 3. 비교 모델

| 모델 | 구성 | 역할 |
| --- | --- | --- |
| `constant` | 과거 학습 Target 평균 | 시간 drift를 포함한 최저 기준 |
| `asof_pitcher` | 투수 누적 성공률, 결측은 학습 평균 | 공식 과거 통계의 무가공 기준 |
| `smoothed_asof_blend` | 투수·타자 누적률을 표본 수로 수축 후 결합 | 간단한 empirical Bayes 기준 |
| `linear_sgd` | 수치 중앙값 대치·표준화, 범주/선수 ID one-hot, 강한 L2 logistic SGD | drift에 비교적 안정적인 선형 기준 |
| `official_rf` | 공식 구조와 동일한 ordinal encoding + median imputation + RF 100개 | 공식 베이스라인 재현 구조 |
| `hist_gradient_boosting` | raw 투수/타자 ID 제외, 저카디널리티 범주 + 수치 피처, 250 iterations | 빠른 비선형 트리 기준 |

`smoothed_asof_blend`의 수축 강도와 투수/타자 가중치는 검증 시즌이 아니라 그 직전 시즌에서 선택했다. 2024 fold에서는 `alpha=100`, 투수 가중치 `0.8`이 선택됐다.

## 4. Rolling 결과

괄호 안은 각 검증 fold에서 환산한 대회식 점수다. Brier는 낮을수록 좋다.

| 모델 | 2022 Brier (점수) | 2023 Brier (점수) | 2024 Brier (점수) | 3-fold 평균 Brier | 양의 skill fold |
| --- | ---: | ---: | ---: | ---: | ---: |
| `linear_sgd` | 0.245701 (1,389.6) | **0.249574 (170.5)** | 0.248928 (351.7) | **0.248068** | **3/3** |
| `official_rf` | 0.243990 (2,076.2) | 0.251661 (0.0) | 0.248767 (416.2) | 0.248139 | 2/3 |
| `hist_gradient_boosting` | **0.243611 (2,228.5)** | 0.253749 (0.0) | **0.248344 (585.6)** | 0.248568 | 2/3 |
| `smoothed_asof_blend` | 0.245915 (1,303.7) | 0.250113 (0.0) | 0.249831 (0.0) | 0.248620 | 1/3 |
| `asof_pitcher` | 0.246874 (919.1) | 0.250567 (0.0) | 0.250274 (0.0) | 0.249238 | 1/3 |
| `constant` | 0.249366 (0.0) | 0.251567 (0.0) | 0.251875 (0.0) | 0.250936 | 0/3 |

3-fold 평균 `raw_skill`은 `linear_sgd` 0.006373, `official_rf` 0.006094, HGB 0.004382 순이다. 최악 fold의 `raw_skill`은 각각 0.001705, -0.006643, -0.014995다. 평균 점수만 보면 2022의 큰 이득과 0 clipping 때문에 불안정한 트리 모델이 과대평가되므로 사용하지 않았다.

## 5. 가장 중요한 오류 분석

### 5.1 `game_type=F`의 2023 체제 변화

| 검증 시즌 | 전체 실제 성공률 | F 행 수 | F 실제 성공률 |
| --- | ---: | ---: | ---: |
| 2022 | 52.89% | 30,448 | **70.87%** |
| 2023 | 50.00% | 25,686 | **47.29%** |
| 2024 | 48.61% | 30,010 | **45.93%** |

2022까지 학습한 모델이 2023 F를 예측할 때 HGB는 평균 `68.69%`, RF는 `64.26%`를 출력했다. 실제는 `47.29%`였고, F 구간 Brier가 각각 `0.29478`, `0.27804`까지 악화됐다. 선형 모델도 `55.05%`로 높았지만 강한 수축 덕분에 전체 fold에서 간신히 양의 skill을 유지했다.

2024에서는 학습 데이터에 이미 2023의 낮은 F 성공률이 포함된다. HGB의 2024 F 평균 예측은 `47.17%`로 실제 `45.93%`에 가까워졌고, 이것이 최근 fold 1위의 주된 이유다. 즉 HGB의 2024 우위가 2025에도 유지되려면 2023 이후의 F 체제가 계속된다는 가정이 필요하다.

### 5.2 2024 세그먼트

아래 점수는 세그먼트별 Target 평균으로 다시 계산한 진단값이므로 공식 전체 점수와 직접 합산할 수 없다.

| 모델 | R Brier / 예측 평균 | F Brier / 예측 평균 | 전체 예측 평균 | 전체 실제 |
| --- | ---: | ---: | ---: | ---: |
| HGB | **0.248411 / 50.02%** | **0.247844 / 47.17%** | 49.68% | 48.61% |
| RF | 0.248487 / 49.98% | 0.250853 / 51.21% | 50.12% | 48.61% |
| Linear | 0.248640 / 49.58% | 0.251079 / 51.04% | 49.75% | 48.61% |

세 모델 모두 전체 성공률을 `1.07~1.51%p` 높게 예측한다. 순위 분별력뿐 아니라 시간 순 calibration 또는 intercept 보정이 다음 점수 개선의 핵심이다.

2024의 완전 cold-start는 투수 81행, 타자 88행뿐이라 모델 간 차이를 일반화하기에는 표본이 너무 작다. 이 구간 결과는 방향성 진단에만 사용한다.

## 6. 속도와 아티팩트

아래는 2026-08-17 현재 Windows PC에서 주 검증 fold를 fresh retrain한 결과다. 데이터 로드와 모델 파일 로드는 예측 시간에서 제외했다.

| 모델 | 학습 | 253,507행 예측 | 저장 크기 |
| --- | ---: | ---: | ---: |
| Linear | 19.1초 | 1.2초 | 32KB |
| RF | 54.8초 | 0.6초 | 3.4MB |
| HGB | 24.2초 | 1.5초 | 427KB |

세 저장 아티팩트를 다시 로드해 2024 전체를 재예측했으며, 저장된 Brier와 `1e-16` 수준까지 일치했다. fresh retrain에서는 Linear/HGB가 저장 결과를 수치 오차 수준으로 재현했고, RF만 Windows 병렬 실행 차이로 Brier가 최대 `9.4e-6`, 환산 점수가 최대 `1.28점` 달랐다. 파일명에 표시된 것처럼 이 모델들은 **2023년까지만 학습한 검증용 모델**이며 최종 제출용 모델이 아니다.

## 7. 재현 방법

현재 PC는 Python 3.11.9와 평가 서버 호환 라이브러리 버전을 사용한다. 새 가상환경 설치 과정은 [`../LOCAL_ENVIRONMENT.md` §3](../LOCAL_ENVIRONMENT.md#3-새로-환경을-만드는-powershell-명령)를 따른다.

```powershell
$env:PYTHONUTF8 = '1'
& .\.venv\Scripts\python.exe -m pip check

# 주 검증 + 검증용 모델 저장
& .\.venv\Scripts\python.exe experiments\run_baselines.py `
  --validation-season 2024 --save-models

# rolling folds
foreach ($Season in 2022, 2023) {
  & .\.venv\Scripts\python.exe experiments\run_baselines.py `
    --validation-season $Season
}
```

사용 버전은 Python 3.11.9, NumPy 1.26.4, pandas 2.0.3, SciPy 1.15.3, scikit-learn 1.8.0, joblib 1.5.3이다. DACON 서버의 Python은 3.11.15다. 현재 PC에서 2024 전체 실행은 데이터 로드를 포함해 약 105초, 2022~2024 세 fold 연속 실행은 `278.2초` 걸렸다.

## 8. 다음 실험 우선순위

1. **시간 순 calibration**: 각 fold에서 직전 시즌 OOF 예측만으로 intercept, slope, shrinkage를 학습한다. → [실험 완료](CALIBRATION_ENSEMBLE_REPORT.md)
2. **안정적 ensemble**: Linear와 HGB/RF의 가중치를 과거 fold에서 정하고, 2023 최악 성능을 제약 조건으로 둔다. → [Linear-HGB 실험 완료](CALIBRATION_ENSEMBLE_REPORT.md)
3. **F 전용 drift 처리**: `season × game_type`, 최근 시즌 가중치, F 전용 모델/보정의 rolling 검증을 비교한다.
4. **ID ablation**: raw 선수 ID, official `asof` 통계, 시간 순 smoothed target encoding을 분리 비교한다.
5. **피처 ablation**: EDA에서 확인한 결정적 중복 피처를 제거하고 확률 calibration 변화를 본다.
6. **Trackman 집계**: 공식 허용 범위 안에서 과거 시즌 투수 물리량/구종 집계를 만들고, 선수 매핑과 cutoff를 검증한다.
7. **최종 재학습·제출 패키지**: 모델 선택 후 2019~2024 전체로 재학습하고 245,789행·10분 제한을 모사한다.

유사 야구 투구/제구 예측 프로젝트와 연구 사례 조사는 이 기본선을 고정한 다음 별도 문서에서 진행한다. 외부 사례의 성능 수치를 그대로 비교하지 않고, 사용 가능한 정보 시점과 Target 정의가 같은지를 먼저 확인해야 한다.
